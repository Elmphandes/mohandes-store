# مكتبة المهندس — متجر إلكتروني

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح. لا يحتاج إلى تثبيت أو خادم لتجربة الواجهة.

## تخصيص بيانات المكتبة
- افتح `script.js`.
- غيّر قيمة `WHATSAPP_NUMBER` إلى رقم المكتبة بصيغة دولية دون + أو مسافات. مثال مصر: `201xxxxxxxxx`.
- عدّل مصفوفة `products` لتغيير أسماء المنتجات والأقسام والأسعار والرموز التعبيرية.
- الأسعار الحالية تجريبية ويمكن تعديلها.

## الملفات
- `index.html`: هيكل الموقع.
- `style.css`: التصميم المتجاوب.
- `script.js`: المنتجات والبحث والتصنيفات والسلة وطلب واتساب.

## ملاحظات مهمة قبل النشر
هذه نسخة واجهة أمامية (Front-end). السلة تحفظ بياناتها في المتصفح باستخدام LocalStorage، وطلب الشراء يُرسل إلى واتساب بعد ضبط رقم المكتبة. لا يوجد حتى الآن نظام دفع إلكتروني أو لوحة تحكم أو قاعدة بيانات أو إدارة مخزون. لإطلاق متجر فعلي متعدد المستخدمين ستحتاج إلى Backend وقاعدة بيانات واستضافة وربط بوابة دفع عند الحاجة.
